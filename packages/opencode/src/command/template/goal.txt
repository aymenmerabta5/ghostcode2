Manage the session goal for autonomous pursuit.

Usage:
- `/goal set <description>` ÔÇö set a new active goal and start pursuing it
- `/goal pause` ÔÇö pause the active goal (stops the autonomous loop)
- `/goal resume` ÔÇö resume the paused goal (restarts the autonomous loop)
- `/goal complete [verification]` ÔÇö mark the goal as completed
- `/goal clear` ÔÇö remove the goal entirely
- `/goal show` ÔÇö display the current goal and its status
